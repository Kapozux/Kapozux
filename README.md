[![Skills](https://skillicons.dev/icons?i=python,js,ts,flask,sqlite,html,css,swift,git&theme=light)](https://skillicons.dev)

**[Ephemeris](https://github.com/Kapozux/Ephemeris)**: It can organize a person's long-term chat history across multiple AI platforms by day, and each conclusion can reference the original sentence and its timestamp. Fully local. From my own data, I got 128,000+ messages and 133,000+ evidence cards. It also has a fork (my classmate made it work on Windows and DeepSeek).

**[Verbatim](https://github.com/Kapozux/_Verbatim_)** [![stars](https://img.shields.io/github/stars/Kapozux/_Verbatim_?style=flat&label=stars)](https://github.com/Kapozux/_Verbatim_/stargazers) [![forks](https://img.shields.io/github/forks/Kapozux/_Verbatim_?style=flat&label=forks)](https://github.com/Kapozux/_Verbatim_/forks): An open-source audio/video notebook that lets you ask across hundreds of hours of audio, and it will give you an answer similar to Google Gemini Notebook: when you click on a source, it will jump to the original second of the source (if it is a video, it will open at that second). It runs fully locally. It has 47 stars and 10 forks.

**[Daemon](https://github.com/Kapozux/Daemon)** ![SWE-bench Lite](https://img.shields.io/badge/SWE--bench%20Lite-57.7%25%20(173%2F300)-blue): A self-written coding agent. It started from the mini-swe-agent tutorial as a learning reference; the routing, planning, context compression, file tools, sub-agents, and evaluation setup were written by me. It can read GitHub issues, modify the code, run the tests, and verify the fix. About 400 lines. SWE-bench Lite: 173/300 (57.7%).

**[Moye](https://github.com/Kapozux/_pdf-dealer_Moye)**: A project that can convert PDF, PPT, and Word into modifiable Markdown, and allows reverse conversion. If there is a text layer, it reads it directly; if not, it will be based on OCR. (It was driven by hard coursework during IB, and by current converters that were inconvenient for me to use.)

I am recently contributing to the [Open Notebook](https://github.com/lfnovo/open-notebook) community (two open pull requests: a source-upload fix and zh-CN translation fixes), and the project has some parts (like its architectural rigor) for me to learn from.
